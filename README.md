# Pell 22 Hair Salon frontend

Standalone Astro 7 + Tailwind CSS 4 frontend, matching the core stack of the Arnav Engineers website. All project files and installed dependencies stay in this folder.

## Run

```sh
npm install
npm run dev
```

Production: `npm run build`. Preview: `npm run preview`.
